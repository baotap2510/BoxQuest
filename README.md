Last updated: September 27, 2026

## Information Collection and Use

We do not require users to create an account or directly provide personal information such as name, address, phone number, or email address in order to use the App.

However, the App uses third-party services that may automatically collect certain information when you use the App.

This information may include:

* Internet Protocol (IP) address
* Device information
* Device identifiers
* Operating system and version
* App version
* Advertising identifiers
* App usage and interaction data
* Advertising interaction data
* Diagnostic and performance information
* Date and time of app usage

The App also uses Firebase Analytics to collect gameplay-related events, including:

* Level completion
* Game wins
* Game progress
* Score-related events
* Gameplay interactions

This information is used to understand how users interact with the App, improve gameplay, identify problems, improve game balance, and enhance the overall user experience.

We do not use gameplay events to directly identify individual users.

Gameplay events may include information such as:

* Level started

* Game won
* Game progress

We use this information to:
